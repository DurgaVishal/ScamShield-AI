# ScamShield AI

An ML-based project to detect suspicious scam messages
and identify potential fraud indicators.

## Problem
Scam messages use fake rewards, urgency, suspicious links,
and requests for sensitive information to deceive people.

## Objective
Build a machine learning application that analyzes text messages,
classifies potential scams, and provides understandable risk indicators.

## Planned Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Streamlit
